ClipSpike for Windows

Windows 10 or 11, 64-bit. There is no public Windows download yet. The first release is still being tested and has not been published.

Windows release coming soon

This site does not host any binaries. When a release is ready, the installer will be linked here from its public download location.

Which file? (once released)

  • Setup (ClipSpike-<version>-x64.exe) — installs per user, no admin rights needed, adds a Start menu entry, and updates itself.
  • Portable (ClipSpike-<version>-x64-portable.exe) — a single exe you run from anywhere, with no install. It never updates itself; download a newer exe to upgrade. Settings and clips still live in %APPDATA%\ClipSpike.

About the SmartScreen warning

Windows may show “Windows protected your PC” the first time you run ClipSpike. That happens because the app is new and has not yet built download reputation with Microsoft, even when a build is signed. It does not mean the file was flagged as malware.

If you trust the download (you got it from the link on this page), choose More info, then Run anyway. If a release is not yet code-signed, its notes say so.
