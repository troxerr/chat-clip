Save your first clip

  1. Open ClipSpike and enter a live Twitch channel you have permission to record.
  2. Select Start Capture and wait for video to start recording.
  3. Select Save highlight now, wait for the export, then open it in Clips.

Which file?

  • Setup (ClipSpike-0.1.5-x64.exe) — installs per user, no admin rights needed, adds a Start menu entry, and updates itself.
  • Portable (ClipSpike-0.1.5-x64-portable.exe) — a single exe you run from anywhere, with no install. It never updates itself; download a newer exe to upgrade. Settings and clips still live in %APPDATA%\ClipSpike.
